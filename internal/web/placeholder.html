Интерфейс не собран

Этот бинарник собран без веб-интерфейса: в него встроена заглушка, а не SPA. API и /healthz при этом работают штатно.

Соберите интерфейс и пересоберите бинарник — make release, либо make ui и затем make build. Образ Docker собирает SPA сам, отдельных шагов не требует.

Проверить, что демон жив, можно так: curl -s localhost:8080/healthz.
